## 二、PRD 标 ✅ 的内容（读码 + 测试覆盖）

都能在完整版里找到对应实现：

- **入口**：`agent/main.py`（Foundry 托管，官方 Agent Framework）和 `space/app.py`（Gradio 演示网页）共用 `learning_coach/server.py` 的同一套组装，有架构测试保证。
- **演示网页（3.5、4.10）**：邀请码（`?key=`）、每天 150 轮和 20 张配图上限（`space/app.py:98-99`）、选项按钮、新会话、清空演示数据、我的笔记、历史对话（最近 20 次）、用邀请码加密的浏览器存储、匿名学习者编号和回访标记。
- **机制一到五**、开场三问、学习记录开/关/删、并行调度、12 次调用预算、45/60/180 秒时限、上下文 token 预算、检索核证、七种图和审图：这部分代码和上次分析的一样（见第四部分），都和 PRD 对得上。
- **提示词**：`instructions.md` 有完整的 A–G 七类意图、E 类闲聊/情绪路线、按学段讲法、`check_question` 规则；`agents/quiz-writer.md` 的输出格式和程序要求的完全一致。

## 三、和 PRD 写法不一致的细节（完整版也存在）

| PRD 位置 | PRD 写法 | 代码实际 | 建议 |
|---|---|---|---|
| 机制二“反复出错就换讲法” | 本次对话里，同知识点、同类疑似错因第二次出现：换讲法 **并且** 额外扣分 | 换讲法的标记按本次对话最近 20 条错因统计（`pipeline.py` `_quiz_grade`）。额外扣分却只看这个知识点**上一次**作答是不是同类答错，而且跨对话统计（`db/memory.py` `_apply_evidence` 的 `previous` 查询）。中间夹一次答对就不扣分，上次对话的错也会算进来 | 二选一：改代码统一条件，或把 PRD 改成如实描述 |
| 3.1 / 3.4 未满 14 岁 | 可能未满 14 岁时，开启记录要家长确认 | 只有开场答了“我自己”加低学段才会拦（`pipeline.py` 处理“开启记录”那段）。开场选“跳过”、回访用户或演示模式下说“开启记录”，会直接开启，不问家长 | 建议补：学段未知时也按“可能未满 14 岁”处理 |
| 机制四 / 附录 A 第 11 条 | 附录写知识图谱“标为部分实现” | 机制四正文里没有对应的 ◐ 条目，只有“可视化展示 ○”。代码里确实有前置、相关字段 | 正文补一条 ◐ |
| 4.1 / 4.7 学习记录跨对话 | 学习笔记跨对话保存 | 只有 Space 入口会传匿名学习者编号；Foundry 托管入口（`api/host.py:45`）只传会话编号，记录只跟着这一次会话 | 演示用 Space 没问题；如果 Foundry 入口也要跨对话，需要补 |

另有一处文档小问题：`README.md:32` 写的七类意图是“讲解/举例/练习/测验/笔记/可视化/边界与情绪”，和 PRD、`instructions.md` 的 A–G 定义不一样，是旧说法。

**PRD 标 ○ 的计划项**（到期复习、复习时间结构化、兴趣主题、知识图谱展示、图的打开率、按角色配模型、题目配图视觉核对）：代码里确实都没有，和 PRD 一致。

## 四、项目共享文件夹里的 `foundry-demo/` 副本

逐文件比对后：`domain/`、`service/`、`db/`、`adapters/` 和完整版**完全相同**；不同的只有外层，而且外层的问题都是在重新包装时引入的，完整版没有：

| 副本里被改的部分 | 后果 |
|---|---|
| 官方 Agent Framework 换成了自写的简化替身；`api/host.py`、`api/http.py` 被改 | 多轮状态每轮丢失。实测连发 4 条消息，每次都回到“这次是谁在学？” |
| `static/index.html` 换成了简易聊天页 | 没有邀请码、选项按钮、笔记、历史对话、每日限额 |
| `config/` 下 6 份提示词被重写 | 输出示例和程序校验的格式对不上（出题的差别最大）；`coordinator.md` 丢了 A–G 定义和大部分规则 |
| `response.schema.json` 加了 800 字上限、`next_step.kind` 改成 `question/quiz` | 长回复加上链接后会超限失败；提示词让用 `quiz`，程序却要求 `question` |
| 测试、评测、`main.py`、`space/` 都不在 | 无法验证 |

项目里的 `foundry-demo_review_report.md` 审的也是这类副本，结论不适用于完整版。
