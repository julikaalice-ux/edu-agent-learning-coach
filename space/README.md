多 agent 学习教练（Azure AI Foundry + Microsoft Agent Framework）：意图编排、检索查证、出题判分、学习记忆、互动图与 AI 配图。访问者无需登录即可体验。

每次打开页面都是全新会话：对话、做题进度和学习记录都不跨页面保留（浏览器只留一个不含内容的「来过了」标记，用来跳过开场问题）。

源码与架构文档见 [GitHub](https://github.com/julikaalice-ux/edu-agent-learning-coach)。
